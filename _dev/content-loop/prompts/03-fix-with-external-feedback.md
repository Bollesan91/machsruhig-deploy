# Round 3 — Fix mit externem Feedback (in Chat A)

Pilot fügt unten den GAP-Output von Chat B ein.

---

Ein externer Reviewer hat deine Saarland-Page bewertet. Hier sein Feedback:

```
[PASTE-ROUND-2-FEEDBACK]
```

Setz **alle GAP-Punkte um**. Schreib die komplette Page neu mit allen Verbesserungen.

**Pflicht:**
- Jeder GAP-Punkt aus der Liste muss in der neuen Version adressiert sein
- Keine Verschlechterung an anderen Stellen
- Wortzahl bleibt mindestens auf altem Niveau, eher höher

**Format:**
- Komplette HTML-Datei, von `<!DOCTYPE html>` bis `</html>`
- Keine Erklärung vor oder nach dem HTML
- Keine Selbst-Kommentare ("Ich habe jetzt X verbessert")
- Nur das fertige HTML

Wenn ein GAP-Punkt sich nicht umsetzen lässt: markier die Stelle mit `<!-- UNSURE: <Begründung> -->` und schreib am Ende einen HTML-Kommentar:

```html
<!-- 
GAP-NICHT-UMGESETZT:
- Punkt X: <Grund>
-->
```

Liefere jetzt v2.
