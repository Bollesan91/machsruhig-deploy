**Konflikte / Entscheidungsbedarf:**

3. **Score-Kalibrierung:** Erfahrungswert der Helper-V3-Pipeline: Erst-Scores liegen systematisch zu hoch; echte Zielerreichung immer per unabhängigem Review verifizieren (wie heute: 6 Runden bis echtes GO 85).

## Cross-Site-Hebel

1. **CTA-Kompass:** genau EIN Haupt-CTA pro Seitentyp (Akut→Checkliste, Kosten→Rechner, Angebot→Prüfer, Stadt→Prüfer/Anfrage, Fristen→Radar, Vorsorge→Check, Trauerrede→Generator, Vorlagen→Copy).
2. **Ergebnis statt Formular:** Eingabe → Ergebnis sofort → Erklärung → PDF/Druck → optional Mail/Anfrage. Nie umgekehrt.
3. **Trust-Satz überall identisch:** „Die Eingaben in diesem Tool bleiben auf deinem Gerät. Nur wenn du aktiv ein Formular absendest oder eine KI-Funktion bestätigst, werden die dafür notwendigen Daten übertragen."
4. **Angebotsprüfer als Produktmitte:** prominent verlinkt von Startseite, Bestattungskosten, Rechner-Ergebnis, Beerdigung planen, Was-tun, Stadtseiten, Bestatter-Übersicht, Sozialbestattung.
5. **Top 5 statt alles.**
