Notfallkarte erstellen — Wichtigste Daten im Portemonnaie

Kostenlose Notfallkarte für das Portemonnaie. Notfallkontakte, Vorerkrankungen, Medikamente und Standorte wichtiger Dokumente (Patientenverfügung, Vorsorgevollmacht) auf einer Karte zum Ausdrucken. In 2 Minuten erstellt.

Methodik

Die Karte folgt dem Format einer EC-Karte und nimmt die wichtigsten Daten auf, die im Notfall (Unfall, Krankenhauseinlieferung, Sterbefall) helfen. Sensible Daten bleiben lokal im Browser — keine Übermittlung an unsere Server, keine Speicherung.
